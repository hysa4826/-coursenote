# 코스노트

GitHub Pages용 개인 일정/코스 웹앱입니다.

## 배포
1. 새 GitHub 저장소를 만듭니다.
2. `index.html`과 `.nojekyll`을 저장소 최상단에 업로드합니다.
3. Settings → Pages → Build and deployment → Source: Deploy from a branch
4. Branch: `main`, Folder: `/ (root)` → Save
5. 생성된 `https://사용자명.github.io/저장소명/` 주소를 Safari에서 엽니다.

별도 빌드, npm, 서버는 필요하지 않습니다.
